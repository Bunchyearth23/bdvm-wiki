# Contribution

1. Ouvrez une issue décrivant problème, version, rôle host/client, save neuve ou existante et preuves disponibles.
2. Limitez une pull request à un module ou fork cohérent.
3. Préservez les frontières de dépendances et l’autorité host-only.
4. Ajoutez un test pour chaque invariant ou régression.
5. Ne joignez jamais de save, log ou capture contenant un secret sans nettoyage.
6. Conservez les crédits, liens upstream et notices de licence.

Les contributions au code BDVM sont publiées sous Apache-2.0. Les forks restent soumis à leur licence ou permission propre.
