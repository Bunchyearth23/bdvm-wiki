# Contributing

Open an issue with the affected module, version, host/client role, new/existing save status, and available evidence. Keep each pull request within one coherent module or fork, preserve dependency boundaries and host authority, and add a test for every invariant or regression.

Remove secrets from saves, logs, and screenshots. Preserve all upstream credits, links, and notices. BDVM contributions use Apache-2.0; integration forks retain their own applicable terms.
