# BDVM.SelfShuntBridge

[Repository](https://github.com/Bunchyearth23/bdvm-selfshunt-bridge) · Version 1.1.0 · Runtime : SelfShunt, SelfShunt.API

Le bridge traduit un contrat industriel autoritaire en lifecycle externe SelfShunt. Il impose host-only, operation ID et job ID valides, schema compatible, payout nul, progression cumulative monotone et reprise de production exactement une fois.

Il ne conduit aucun train et ne remplace pas le moteur économique BDVM.
