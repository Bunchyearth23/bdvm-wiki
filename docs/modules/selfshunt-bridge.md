# BDVM.SelfShuntBridge

[Repository](https://github.com/Bunchyearth23/bdvm-selfshunt-bridge) · 1.1.0 · Runtime: SelfShunt and SelfShunt.API

Maps authoritative industrial contracts to SelfShunt's external lifecycle. It enforces host-only execution, valid operation/job IDs, compatible schema, zero SelfShunt payout, monotonic progress, deduplicated delivery, and exactly-once production resumption.
