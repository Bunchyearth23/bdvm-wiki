# BDVM.Full

[Repository](https://github.com/Bunchyearth23/bdvm-full) · 0.3.0 beta · Integration bundle

Composes the thirteen other modules, Unity adapters, in-game UI, and four third-party integrations without duplicate runtime types. UMM requirements are Multiplayer, SelfShunt, PassengerJobs, and RemoteDispatchLive; matching fork packages provide the required APIs, and PassengerJobs also requires DVLangHelper.

`F7` opens the UI only in mouse mode. World interaction is blocked while the window is open.
