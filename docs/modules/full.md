# BDVM.Full

[Repository](https://github.com/Bunchyearth23/bdvm-full) · Version 0.3.0 beta · Bundle d’intégration

Full compose les treize autres modules, les adapters Unity, l’interface en jeu et les quatre intégrations tierces. Il évite les types runtime dupliqués et fournit un profil complet prêt à tester.

## Requirements UMM

`Multiplayer`, `SelfShunt`, `PassengerJobs` et `RemoteDispatchLive`. Les APIs nécessaires sont fournies par les packages de leurs forks ; PassengerJobs requiert aussi DVLangHelper.

La touche `F7` affiche l’interface seulement en mouse mode. Pendant son ouverture, les interactions avec le monde sont bloquées.
