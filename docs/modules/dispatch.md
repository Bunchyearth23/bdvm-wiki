# BDVM.Dispatch

[Repository](https://github.com/Bunchyearth23/bdvm-dispatch) · Version 1.1.0 · Runtime : Web, RemoteDispatchLive

Dispatch possède les vues ferroviaires : carte, trains, voies, aiguillages, signaux, occupations et préparation d’itinéraires. Les fonctions économiques appartiennent à Management.

RemoteDispatchLive fournit actuellement le host HTTP et le transport. Dispatch reste séparé afin qu’un autre transport puisse le remplacer.
