# BDVM.Management

[Repository](https://github.com/Bunchyearth23/bdvm-management) · Version 1.3.0 · Runtime : Web

Management expose compagnies, wallets, flotte, marché, locations, contrats, industrie, voyageurs, financement et triage. Les vues reçoivent des snapshots autoritaires et les boutons envoient uniquement des intentions versionnées.

Les actions destructives exigent confirmation. Une panne du frontend ne modifie pas le domaine.
