# BDVM.MultiplayerBridge

[Repository](https://github.com/Bunchyearth23/bdvm-multiplayer-bridge) · 1.1.0 · Runtime: Multiplayer and MultiplayerAPI

Adapts peer identity, host/client role, packets, reconnects, and snapshots to BDVM contracts. It contains no fork code and fails closed when the API or supported version is missing.
