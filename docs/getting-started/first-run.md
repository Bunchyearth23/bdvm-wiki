# Première partie

## Carrière de test

Utilisez une **nouvelle carrière non tutorielle**. Le mode strict refuse volontairement une save vanilla existante ou tutorielle avant toute mutation. Cela évite d’adopter comme actifs BDVM des véhicules générés par une autre économie.

## Démarrage conseillé

1. Démarrez avec le contrôle strict de population désactivé.
2. Vérifiez dans `Player.log` que `BDVM.Full`, ses modules et les quatre forks sont actifs.
3. Passez en mouse mode avec `Alt`, puis ouvrez l’interface avec `F7`.
4. Créez une compagnie à solde nul ou restez indépendant.
5. Vérifiez le grant starter unique.
6. Configurez au moins un dépôt ou rail de service réel avant d’activer le mode strict.
7. Sauvegardez, revenez au menu et rechargez pour contrôler la persistance.

## Résultat attendu

L’interface doit bloquer les interactions avec le monde lorsqu’elle est ouverte. Le wallet personnel et celui de la compagnie restent distincts. Toute action refusée affiche un code et produit un log corrélé, sans débit ni création physique partielle.
