# First session

Use a **new, non-tutorial career**. Strict mode refuses unsupported careers before mutation so naturally generated equipment cannot be silently adopted as BDVM property.

1. Start with strict population control disabled.
2. Confirm in `Player.log` that Full, its modules, and all required forks are active.
3. Enter mouse mode with `Alt`, then open BDVM with `F7`.
4. Create a zero-balance company or remain independent.
5. Verify the one-time starter entitlement.
6. Configure at least one real depot or service track before enabling strict mode.
7. Save, return to the menu, and reload to verify persistence.

While open, the in-game window must block world interaction. Personal and company wallets must remain distinct. A refused action must produce a correlated result without a debit or partial physical effect.
