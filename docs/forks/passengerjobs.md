# PassengerJobs fork

[Bunchyearth23/DVPassengerJobs](https://github.com/Bunchyearth23/DVPassengerJobs) derives from [katycat5e/DVPassengerJobs](https://github.com/katycat5e/DVPassengerJobs), audited revision `9bb668cbc2f3d270d282b2b3297667f01bec3e18`, under MIT.

It adds PassengerJobs.API plus idempotent lifecycle, host/client, payout-capture, and consist-reuse protections. Its own update feed prevents an upstream package without the API from replacing the integration build.
