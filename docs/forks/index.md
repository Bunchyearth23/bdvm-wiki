# Forks d’intégration

Les bridges BDVM utilisent quatre forks publics. Chaque fork conserve l’historique, les crédits, le lien upstream et la licence ou permission applicable. Un « bridge » n’est pas le mod d’origine : les deux doivent être installés lorsque le module l’exige.

| Fork BDVM | Upstream | Licence | Branche d’intégration |
| --- | --- | --- | --- |
| [dv-multiplayer](https://github.com/Bunchyearth23/dv-multiplayer) | [AMacro](https://github.com/AMacro/dv-multiplayer) | Apache-2.0 | `bdvm-integration` |
| [DV-SelfShunter](https://github.com/Bunchyearth23/DV-SelfShunter) | [Chump-the-Lump](https://github.com/Chump-the-Lump/DV-SelfShunter) | Permission de fork documentée | `dvcompany-integration` |
| [DVPassengerJobs](https://github.com/Bunchyearth23/DVPassengerJobs) | [katycat5e](https://github.com/katycat5e/DVPassengerJobs) | MIT | `bdvm-integration` |
| [dv-remote-dispatch](https://github.com/Bunchyearth23/dv-remote-dispatch) | [mspielberg](https://github.com/mspielberg/dv-remote-dispatch) | MIT | `bdvm-integration` |
